# Richard E. Nelson: research website (draft)

A static site: plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser to preview it (it loads d3 and Google Fonts from the web).

Alec Chapman drafted it in October 2026 from public sources: the University of Utah faculty page, Google Scholar, PubMed and NIH RePORTER.

## Files

| File | What it holds |
|---|---|
| `index.html` | Page structure and the six sections |
| `site.css` | The three layouts (`html[data-layout]`) and four colors (`html[data-pal]`) |
| `site.js` | Fills the page from `data.js`; sets the layout (sidebar), color (navy) and default paper map in its `defaults` object |
| `viz.js` | Topic x year paper timeline, topic network, research timeline, searchable paper list |
| `data.js` | Generated by `build-data.py`: profile text, topics, papers, grants, timeline |
| `build-data.py` | Rebuilds `data.js` from `source/rich.json` (`python3 build-data.py`) |
| `source/rich.json` | The raw public data: papers with citation counts, grants, appointments |

## Finishing it

1. Layout and color are chosen (sidebar, navy) and the draft-options panel has been removed. To change them, edit `defaults` in `site.js`.
2. Add a headshot: save it as `photo.jpg` next to `index.html`. It fills the `.photo` box, cropped to a square (a circle in the sidebar layout). Until the file exists, the `RN` initials show instead.
3. Check the paper list and topic tags. Tags come from keyword rules, and Google Scholar shortens long author lists, so some last-author papers are not marked.

## Publishing on GitHub Pages

1. Create a public repository named `<username>.github.io`, or any other name.
2. Commit these files at the repository root.
3. In the repository's Settings > Pages, choose "Deploy from a branch", `main`, `/ (root)`.

The site appears at `https://<username>.github.io/` (or `/<repo-name>/`) within a minute or two.
